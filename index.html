First — the terms

Terms used in this tutorial

Tutorials often use terms without explaining them. Here are the key ones, in plain language.

IDE

Short for the app where you write and run your code. It colours your words, points out typos, and has a ▶ button that launches your game.

In Scratch: the editor where all your blocks live.

Language

The words and rules you type to give instructions. We'll use Python — one of the most popular, and one of the easiest to read.

In Scratch: the blocks were a language too — just drag-and-drop instead of typed.

Game engine

A toolbox that already knows how to draw pictures, move things and detect crashes — so you build the fun part, not the plumbing.

For 2D Python games: Pygame Zero and Pygame.

Run

Pressing ▶ to make your code actually happen. If it works, your game moves. If not, you get an error — and that's just a clue.

In Scratch: clicking the green flag.

Bug / Debug

A bug is when your code does something you didn't mean. Debugging is playing detective to find out why. Pros do this all day, every day.

In Scratch: when the sprite goes the wrong way and you hunt for the block.

Syntax

The exact spelling and punctuation a language expects. Forget a bracket and it complains — annoying, but normal, and easy to fix.

In Scratch: you couldn't really get this wrong — blocks only snap where they fit.

The roadmap

Three steps to your first Python game

Work through these steps in order. Each one builds on the last.

Get set up

A few one-time installs and you're set for good. Grab Python (the language) and VS Code (where you'll write it). Open VS Code, click the Extensions icon on the left, and add the Python extension from Microsoft — it quietly brings Pylance along, which catches your typos and finishes your lines. That's the only must-have; indent-rainbow is a nice extra, since Python is fussy about indenting. Last, in the VS Code terminal, type pip install pgzero to add Pygame Zero — then run any game with pgzrun mygame.py.

Make things move

Learn the Pygame Zero basics. Put a character on screen, move it with the arrow keys, and add gravity so it falls. You can try exactly this in the box further down.

Build your jump-and-run

Put it all together. Platforms to stand on, a jump, things to dodge, and a way to win. That's your first real game — the tutorials for it are further down.

The whole game, in 9 lines

WIDTH = 320 HEIGHT = 320 player = Actor('box', (40, 40)) def draw(): screen.clear() player.draw() def update(): if keyboard.right: player.x += 4 if keyboard.left: player.x -= 4 if keyboard.up: player.y -= 4 if keyboard.down: player.y += 4

This reads as: "if the right key is down, add 4 to the player's x." It's the same logic as your move 10 steps block, written as code.
